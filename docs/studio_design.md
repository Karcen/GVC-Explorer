# Desktop and atlas design notes

The desktop launcher and offline atlas keep the WWZ accounts separate from presentation. Chart CSVs carry signed amounts. Negative values are not trimmed. Bilateral comparisons use gross exports rather than an unweighted mean of component shares. The eight figures are independent single-panel plots; different aggregations are labelled in each figure. The default benchmark is a historical workbook, not a current trade estimate.

The figure workflow uses [Yuan1z0825/nature-skills, nature-figure](https://github.com/Yuan1z0825/nature-skills/tree/main/skills/nature-figure) guidance on physical dimensions, editable text, legible final-size labels, consistent encoding and recoverable source data. The publication figure is 183 × 116 mm, with editable PDF and SVG text and a 450 dpi PNG. PDF text and page bounds are checked independently with PyMuPDF. The frontend uses [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) for layout and typographic hierarchy, including a compact reading surface, legible signed amounts, clear filter scope, and keyboard-operable controls. No CDN or web font is needed. Published [English](https://github.com/blader/humanizer) and [Chinese](https://github.com/op7418/Humanizer-zh) editing guidance informed the interface and documentation. The unmodified upstream Nature Figure PDF text auditor (Git blob `10830f22870fe00f365df3989e0af56e6481cb21`, Apache-2.0) ships in `src/gvc/vendor/nature_figure/` and runs against every exported PDF with a 6.5 pt floor. See `nature_text_audit.json` in each figure directory. Other upstream tools, including the separate collision auditor, are not bundled. No external installer or script processed the IO data.

On Linux install the distribution's Tk package and a CJK system font (such as Noto Sans CJK SC) for Chinese plots. macOS may flag unsigned downloaded launchers; use the manual Python steps in the README rather than disabling system protection. The `.command` and `.bat` scripts create a project-local virtual environment and let pip install declared dependencies. Only the Linux Tk runtime was exercised here.

Each annual result carries its accounting basis. `VA+TLS` means that the attribution includes net taxes on products. This is not an official OECD TiVA series. For new classifications, extend the codebook explicitly rather than repurposing the 2007 axis labels. File hashes and baseline provenance are recorded in `reports/legacy_axis_audit.json` and per-run manifests.

## Light interface

The desktop and setup window share `ui_theme.py`. The offline atlas uses `src/gvc/web/design.css` and the formula generator reads `src/gvc/web/methods.css`; both embed the stylesheet in each HTML file. The chart data, labels, equations and publication figures are unchanged. The desktop and the two reading surfaces keep the English notice “For research only” in both languages. Native file pickers and native alerts belong to the operating system. The optional Streamlit viewer uses `.streamlit/config.toml` and the layout in `app.py`.
